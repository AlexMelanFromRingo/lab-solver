# lab-solver

Решатель детерминированных частей университетских лабораторных: 184 модуля примерно по 26
курсам бакалаврата и магистратуры — криптография, теория информации и кодирование, сети,
архитектура ЭВМ и микропроцессоры, системное ПО, программирование, проектирование ИС,
киберфизические системы, базы данных, ПЛИС и другие.

**[Открыть сайт →](https://alexmelanfromringo.github.io/lab-solver/)**

## Идея

Лабораторная обычно состоит из двух частей: **вариант**, который назначают по номеру в
списке группы, и **алгоритм**, который из этого варианта детерминированно выводит ответ.
Вариант выбирать не нужно — его выдают. А вот применение алгоритма к своим числам — чистая
математика, которую можно проверить программой.

Здесь собраны только такие модули: там, где нашлась таблица вариантов из методички —
она перенесена как есть, без додумывания. Там, где методичка допускает разночтения — это
явно помечено и вынесено в редактируемое поле, а не зашито тихо «как получится». Часть
модулей — точные переносы реальных студенческих решателей (C++/Python/Rust с занятий),
сверенные побайтово с их выводом на компилируемых бинарниках, а не переписанные заново по
учебнику.

Все вычисления — на клиенте, в браузере. Ничего никуда не отправляется.

## Модули (184)

Сейчас — **184 модуля** примерно по 26 университетским курсам (бакалаврат и магистратура ПКМ).
Навигация на сайте — по дисциплинам; ниже — общими мазками по областям.

- **Криптография и криптология** — сеть Фейстеля по варианту (24 варианта), RSA, PGP, ГПСЧ
  (серединные квадраты), классические шифры и криптоанализ (Цезарь/Виженер/гамма/OTP), S-DES,
  BBS/LFSR, ГОСТ 28147-89, RC4.
- **Теория чисел и основы ИБ** — алгоритм Евклида и расширенный, факторизация (пробы, Ферма),
  решето Эратосфена, решение сравнений, тесты на простоту (пробное деление, Ферма,
  Миллер-Рабин, Соловей-Штрассен), система сравнений (КТО), алгоритм Луна.
- **Теория информации и кодирование** — Unicode, энтропия / Шеннон-Фано / Хаффман, сжатие,
  контроль ошибок и CRC, непрерывный канал (Шеннон-Хартли), линейное кодирование сигналов;
  помехоустойчивые коды Хэмминга, Рида-Соломона, полярные и LDPC.
- **Архитектура и микропроцессорные системы** — язык логических схем JOLS-M (симулятор с
  пошаговым выполнением), арифметика с фиксированной и плавающей точкой, учебный МПК и курсовая.
- **Сети** — топологии в Cisco Packet Tracer, ARP, статическая маршрутизация, Cisco IOS, маски
  и префиксы IPv4; локальные сети (Ethernet / Token Ring / FDDI с расчётами), фильтрация
  пакетов, NAT, туннелирование, VLAN, сканирование портов.
- **Системное ПО и ОС** — Unix и QNX Neutrino (ОСРВ: сообщения, таймеры, инверсия приоритетов),
  WinAPI, потоки и процессы, виртуальная память.
- **Программирование** — основы на C++ (12 работ), структуры/ООП/STL, проектный практикум
  (моделирование устройств, оценка сложности алгоритмов).
- **Прикладные и инженерные** — ПЛИС и VHDL (Xilinx), базы данных (Microsoft Access —
  DDL/DML/DQL, защита, проектирование), численные методы, дискретная математика (графы,
  транспортная задача), электрические и магнитные цепи, схемотехника (OrCAD/PSpice), ИИ
  (токенизаторы LLM, нечёткая логика), охрана труда, методы защиты информации (биометрия,
  «ЛОЗА-1»).

Отдельными разделами ниже расписаны модули с нестандартным поведением — готовая работа и
чтение своего файла варианта: проектирование ИС в сетях Интернет, киберфизические системы,
Cisco CyberOps и ИТ в управленческой деятельности.

**Проектирование ИС в сетях Интернет** — пять модулей по номерам лабораторных, всё строго
по методичке. Лаба 1: установка Docker на Windows, WSL 2, macOS и Linux с командами и
граблями каждой конфигурации. Лаба 2 (15 + 13 вариантов, выбираются независимо): расчёт
обеих функций с журналом промежуточных величин и задание второй программы — адреса сети и
узла в двоичном виде, системы счисления, календарь, координаты ячейки, шахматная доска,
пирамиды, зодиак. Лаба 3: окружение из PHP, MySQL и phpMyAdmin и справочник с операциями
CRUD на одну из 14 тем. Лаба 4: Laravel и Laravel Breeze в Docker по Readme из архива
курса. Лаба 5: персональная страница на Laravel с Breeze, перечнем работ из базы и формой
обратной связи — накладка на проект из лабы 4.

В этих модулях выдаётся **готовая работа**: студент вписывает ПІБ и группу, выбирает одно из
четырёх оформлений (от «как в методичке» до максимального) и скачивает архив с каталогом
`project/` (или `lara/`), как в методичке. Данные подставляются в код в браузере, цвет
оформления выводится из ПІБ — у разных студентов работы не совпадают. Шаблоны с
заполнителями, их описание (`index.json`) и снимки оформлений лежат статикой в
`public/pismi`; их выкладывает `tools/solver/export_to_site.py` из рабочего репозитория
курса. Подстановка на сайте сверяется побайтно с `render.py` курса:
`node scripts/pismi-parity.mjs --course <…>/tools/solver`.

**Теория проектирования киберфизических систем** — семь модулей по методичкам КС ЛР1–ЛР7:
топология технологических объектов и уточнение кабельных расстояний, минимальные остовные
деревья по Краскалу и квадрат расстояний, условная информационная мощность и индекс системы,
время команд, ФПБ и всех заявок по цепочкам с ветвлениями, быстродействие МКП на смесях команд
и транзакций, информационные потоки (управляющие воздействия, сообщения, обращения к БД) с
графами, максимальное остовное дерево потоков, КОК, загрузка МКП и место центральной БД. Свой
файл варианта (.xlsx преподавателя) читается прямо в браузере — без сторонних библиотек,
распаковкой zip через `DecompressionStream`. Без файла ЛР1–ЛР4 показывают примеры методичек
(расчёт совпадает с их таблицами), а ЛР5–ЛР7 — вариант 1 из файлов преподавателя
(`public/kfs/variant-1.json`, только значения ячеек): полных данных примера для них в
методичках нет. Найденные опечатки методичек вынесены на страницы.

**Практика использования аппаратно-программных средств Cisco** — 19 работ курса Cisco
CyberOps Associate (модули 1–5): исследовательские задания с разобранными ответами и
лабораторные в Windows 11 и в машине курса на Ubuntu 22.04 — порядок с командами, что снимать на
экран, ответы на вопросы и то, где методичка, написанная под старую машину на Arch Linux и
Windows 10, расходится с тем, что видно сейчас.

**ИТ в управленческой деятельности** — три модуля по номерам лабораторных. Лаба 1:
таблица по своим данным и предпросмотр точечной, вертикальной и круговой диаграмм,
требования к оформлению дословно из задания. Лаба 2: графики в SMath и Mathcad — готовая
запись под выбранные функцию, массив и импорт из Excel и та же работа на Python. Лаба 3:
классификатор изображений в Lobe — ход работы с тем, где Lobe ломает модель, запуск в
Windows, в Windows Sandbox и под wine, та же работа кодом на PyTorch и TensorFlow и
результаты всех способов на одних и тех же 40 проверочных изображениях. Готовый отчёт и
скрипты третьей работы лежат в `public/it`; их выкладывает `tools/export_to_site.py` из
рабочего репозитория курса, заменяя имена и собирая отчёт заново.

## Как устроено

- **Next.js 16** (App Router, статический экспорт) + **React 19** + **TypeScript**
- **Tailwind CSS v4** — тёмная тема, категории модулей закодированы цветом
- **Framer Motion** — анимации
- Вся логика — чистые TypeScript-функции в `src/lib/algorithms/*`, независимые от UI;
  страницы в `src/app/modules/*` — тонкая обвязка вокруг них

## Разработка

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # статический экспорт в ./out
```

## Источники

Каждый модуль указывает источник на своей странице — реальный код лабораторной, отчёт с
методички или сторонний открытый инструмент (`error-codes-explorer`, `primary_tests`,
`card-check-algo`, `jolsm-toolkit`, `rust-rsa-from-scratch`). Там, где формула
реконструирована по числам из реального отчёта (а не взята из учебника), это отдельно
отмечено в описании модуля.
