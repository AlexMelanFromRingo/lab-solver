# Windows Sandbox для ЛР3

Lobe – застосунок лише для Windows. Щоб запустити його штатно (без латок, з GPU) і не
встановлювати в основну систему, ЛР3 виконано у Windows Sandbox: одноразовій Windows,
яка стирається, щойно закрити її вікно. Варіант з wine описано в `../lobe-wine.md`.

## Файли

| Файл | Що робить |
|---|---|
| `Lobe.wsb` | конфігурація пісочниці: vGPU, 12 ГБ пам'яті, мережа, спільна тека, автозапуск агента |
| `agent.ps1` | агент усередині пісочниці: виконує скрипти з `io\cmd`, пише відповіді в `io\out` |
| `sbx.sh` | те саме з боку WSL: `sbx.sh 'Shot знімок'`, `sbx.sh -f команди.ps1` |

Сценарій перевірки моделі через локальний API Lobe – `../lr3_validate.ps1`.

## Порядок

1. Увімкнути компонент (потрібні права адміністратора і перезапуск):
   `dism /online /enable-feature /featurename:Containers-DisposableClientVM /all`.
   Доступний у Windows Pro, Enterprise, Education.
2. Створити на хості спільну теку (у `Lobe.wsb` – `C:\Users\user\LobeSandbox`)
   з підтеками `agent`, `io`, `setup` (інсталятор), `data` (зображення), `shots`, `export`.
   Покласти туди `agent.ps1` і `sbx.sh`.
3. Запустити `Lobe.wsb` (подвійне клацання або з WSL:
   `cmd.exe /c start "" "C:\...\Lobe.wsb"`). Коли агент стартує, в `io\alive.txt`
   щоп'ять секунд оновлюється час.
4. Керувати з WSL, наприклад:
   `sbx.sh 'Start-Process C:\LobeSandbox\setup\Lobe.exe; Start-Sleep 8; Wins | Format-Table'`.
5. Вимкнути компонент, коли більше не потрібен:
   `dism /online /disable-feature /featurename:Containers-DisposableClientVM` і перезапуск.

## Помічники агента

`Wins` (видимі вікна з координатами), `Win`/`Focus` (знайти, вивести на передній план),
`Click x y [-Right] [-Double]`, `MoveTo`, `Wheel`, `TypeText` (юнікод, кирилиця без
залежності від розкладки), `Key 'ctrl+a'`, `Shot ім'я [заголовок вікна]` (знімок в
`shots\`).

## Граблі

* PowerShell 5.1 читає скрипт без BOM у кодуванні ANSI, і кирилиця ламає розбір
  (лапки-«ялинки» cp1252). `agent.ps1` зберігати в UTF-8 з BOM; команди від `sbx.sh`
  агент читає явно як UTF-8.
* `SetForegroundWindow` з фонового процесу дозволений лише після натискання Alt, але
  самотній Alt активує меню вікна, і наступна літера губиться. Між натисканням і
  відпусканням Alt агент натискає F24.
* Агент однопотоковий: команда з довгим очікуванням блокує всі наступні.
* Вікно пісочниці не згортати: згорнута сесія може віддавати чорні знімки. Перекривати
  іншими вікнами можна.
* Функція `Move` в PowerShell не працює: псевдонім `move` (Move-Item) має вищий
  пріоритет, ніж функція, тому помічник названо `MoveTo`.
